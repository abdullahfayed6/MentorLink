# TypeScript Advanced Features

## Type System Fundamentals

### Basic Types and Annotations
- **Primitive Types**: string, number, boolean, null, undefined
- **Array Types**: number[], Array<string> syntax variations
- **Object Types**: Interface definitions and inline types
- **Function Types**: Parameter and return type annotations
- **Union Types**: Multiple possible types with | operator

### Advanced Type Features
- **Generics**: Type parameters for reusable components
- **Conditional Types**: Type logic with extends keyword
- **Mapped Types**: Transforming existing types
- **Template Literal Types**: String manipulation at type level
- **Utility Types**: Partial, Required, Pick, Omit built-ins

### Type Guards and Narrowing
- **typeof Guards**: Runtime type checking
- **instanceof Guards**: Class instance checking
- **Custom Type Guards**: User-defined type predicates
- **Discriminated Unions**: Type-safe union handling
- **Assertion Functions**: Functions that assert types

## Object-Oriented Programming

### Classes and Inheritance
- **Class Declaration**: Properties, methods, constructors
- **Access Modifiers**: public, private, protected visibility
- **Inheritance**: extends keyword and super calls
- **Abstract Classes**: Base classes that cannot be instantiated
- **Static Members**: Class-level properties and methods

### Interfaces and Contracts
- **Interface Declaration**: Shape definitions for objects
- **Optional Properties**: ? operator for optional members
- **Index Signatures**: Dynamic property access patterns
- **Interface Inheritance**: Extending existing interfaces
- **Interface Merging**: Declaration merging capabilities

### Advanced OOP Concepts
- **Method Overloading**: Multiple method signatures
- **Property Decorators**: Metadata and behavior modification
- **Mixins**: Multiple inheritance patterns
- **Dependency Injection**: Inversion of control patterns
- **Design Patterns**: Singleton, Factory, Observer implementations

## Modern TypeScript Features

### Module System
- **ES Modules**: import/export syntax and semantics
- **Module Resolution**: Node.js and classic strategies
- **Namespace**: Organizing code with namespace keyword
- **Module Augmentation**: Extending existing modules
- **Triple-Slash Directives**: Compiler directives

### Configuration and Tooling
- **tsconfig.json**: Compiler configuration options
- **Strict Mode**: Enhanced type checking flags
- **Path Mapping**: Module resolution customization
- **Declaration Files**: .d.ts type definitions
- **Source Maps**: Debugging compiled JavaScript

### Integration and Ecosystem
- **React with TypeScript**: Typed component development
- **Node.js with TypeScript**: Server-side development
- **Testing**: Jest, Mocha type-safe testing
- **Build Tools**: Webpack, Rollup, Vite integration
- **Linting**: ESLint and TypeScript-ESLint rules
