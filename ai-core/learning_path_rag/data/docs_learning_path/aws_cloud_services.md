# AWS Cloud Services

## AWS Core Services

### Compute Services
- **EC2 (Elastic Compute Cloud)**: Virtual servers in the cloud
- **Lambda**: Serverless computing functions
- **ECS (Elastic Container Service)**: Docker container orchestration
- **EKS (Elastic Kubernetes Service)**: Managed Kubernetes clusters
- **Elastic Beanstalk**: Platform-as-a-Service deployment

### Storage Services
- **S3 (Simple Storage Service)**: Object storage with high durability
- **EBS (Elastic Block Store)**: Block storage for EC2 instances
- **EFS (Elastic File System)**: Managed file system storage
- **Glacier**: Long-term archival and backup storage
- **Storage Gateway**: Hybrid cloud storage integration

### Database Services
- **RDS (Relational Database Service)**: Managed relational databases
- **DynamoDB**: NoSQL database service
- **Redshift**: Data warehouse solution
- **ElastiCache**: In-memory caching service
- **Aurora**: High-performance MySQL/PostgreSQL compatible database

## Networking and Security

### Networking Services
- **VPC (Virtual Private Cloud)**: Isolated network environments
- **Subnets**: Public and private network segments
- **Internet Gateway**: Internet connectivity for VPC
- **NAT Gateway**: Outbound internet access for private subnets
- **Route 53**: DNS and domain registration service

### Security Services
- **IAM (Identity and Access Management)**: User and permission management
- **Security Groups**: Virtual firewalls for instances
- **Network ACLs**: Subnet-level security controls
- **KMS (Key Management Service)**: Encryption key management
- **CloudTrail**: API call logging and auditing

### Content Delivery and API Management
- **CloudFront**: Global content delivery network
- **API Gateway**: Managed API creation and deployment
- **Application Load Balancer**: Layer 7 load balancing
- **Network Load Balancer**: Layer 4 load balancing
- **AWS Certificate Manager**: SSL/TLS certificate management

## DevOps and Monitoring

### Deployment and Automation
- **CloudFormation**: Infrastructure as Code templates
- **CodePipeline**: Continuous integration and deployment
- **CodeBuild**: Managed build service
- **CodeDeploy**: Application deployment automation
- **Systems Manager**: Instance management and automation

### Monitoring and Logging
- **CloudWatch**: Monitoring and alerting service
- **CloudWatch Logs**: Centralized log management
- **X-Ray**: Distributed application tracing
- **Config**: Configuration compliance monitoring
- **Trusted Advisor**: Best practices recommendations

### Cost Management
- **Cost Explorer**: Cost analysis and forecasting
- **Budgets**: Cost and usage budget alerts
- **Reserved Instances**: Cost optimization for predictable workloads
- **Spot Instances**: Cost-effective computing for flexible workloads
- **Cost Allocation Tags**: Resource cost tracking
