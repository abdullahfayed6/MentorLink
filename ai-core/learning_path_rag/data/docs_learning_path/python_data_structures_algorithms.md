# Python Data Structures and Algorithms

## Basic Data Structures

### Lists and Arrays
- **List Operations**: append, insert, remove, pop, index
- **List Comprehensions**: Creating lists with conditions
- **Slicing**: Extracting sublists with slice notation
- **Sorting**: sort() method and sorted() function
- **Array Module**: Fixed-type arrays for numeric data

### Dictionaries and Sets
- **Dictionary Methods**: get, keys, values, items, update
- **Dictionary Comprehensions**: Creating dictionaries efficiently
- **DefaultDict**: Handling missing keys with default values
- **Sets**: Unique collections and set operations
- **Frozenset**: Immutable sets for hashable collections

### Strings and Tuples
- **String Methods**: split, join, replace, strip, format
- **String Formatting**: f-strings, .format(), % formatting
- **Regular Expressions**: Pattern matching with re module
- **Tuples**: Immutable sequences and named tuples
- **Tuple Unpacking**: Multiple assignment from tuples

## Algorithm Fundamentals

### Time and Space Complexity
- **Big O Notation**: Analyzing algorithm efficiency
- **Best, Average, Worst Case**: Different complexity scenarios
- **Space Complexity**: Memory usage analysis
- **Amortized Analysis**: Average case over sequence of operations
- **Trade-offs**: Time vs space complexity decisions

### Sorting Algorithms
- **Bubble Sort**: Simple comparison-based sorting
- **Selection Sort**: Finding minimum/maximum iteratively
- **Insertion Sort**: Building sorted array incrementally
- **Merge Sort**: Divide and conquer sorting approach
- **Quick Sort**: Partition-based recursive sorting

### Searching Algorithms
- **Linear Search**: Sequential element searching
- **Binary Search**: Efficient search in sorted arrays
- **Hash Tables**: O(1) average case lookup
- **Binary Search Trees**: Ordered tree structures
- **Breadth-First Search**: Graph traversal algorithm

## Advanced Data Structures

### Trees and Graphs
- **Binary Trees**: Hierarchical data structures
- **Tree Traversal**: Inorder, preorder, postorder, level-order
- **Balanced Trees**: AVL trees, Red-Black trees
- **Graphs**: Vertices, edges, adjacency representations
- **Graph Algorithms**: DFS, BFS, shortest path algorithms

### Stacks and Queues
- **Stack Operations**: push, pop, peek, isEmpty
- **Stack Applications**: Function calls, expression evaluation
- **Queue Operations**: enqueue, dequeue, front, rear
- **Priority Queues**: Heap-based priority ordering
- **Deque**: Double-ended queue operations

### Hash Tables and Heaps
- **Hash Functions**: Mapping keys to array indices
- **Collision Resolution**: Chaining vs open addressing
- **Load Factor**: Managing hash table performance
- **Min/Max Heaps**: Complete binary tree properties
- **Heap Operations**: insert, delete, heapify
