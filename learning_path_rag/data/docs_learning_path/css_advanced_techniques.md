# CSS Advanced Techniques

## CSS Layout Systems

### Flexbox Layout
- **Flex Container**: display: flex, flex-direction, flex-wrap
- **Flex Items**: flex-grow, flex-shrink, flex-basis
- **Alignment**: justify-content, align-items, align-self
- **Flex Shorthand**: Combined flex property values
- **Responsive Design**: Flexible layouts for different screens

### CSS Grid Layout
- **Grid Container**: display: grid, grid-template-columns/rows
- **Grid Items**: grid-column, grid-row, grid-area
- **Grid Lines**: Naming and positioning with line numbers
- **Grid Template Areas**: Visual grid layout definition
- **Auto-Placement**: Automatic grid item positioning

### Positioning and Float
- **Position Property**: static, relative, absolute, fixed, sticky
- **Z-Index**: Stacking context and layer ordering
- **Float**: Legacy layout technique and clearfix
- **Box Model**: Content, padding, border, margin
- **Box-Sizing**: Border-box vs content-box sizing

## Advanced Styling Techniques

### CSS Animations and Transitions
- **CSS Transitions**: Property changes over time
- **Transition Properties**: duration, delay, timing-function
- **CSS Animations**: Keyframe-based animations
- **Animation Properties**: iteration-count, direction, fill-mode
- **Performance**: Hardware acceleration and will-change

### CSS Custom Properties
- **CSS Variables**: --custom-property syntax
- **Variable Scope**: Global and local custom properties
- **Dynamic Updates**: JavaScript manipulation of CSS variables
- **Fallback Values**: Default values for unsupported browsers
- **Theming**: Creating switchable themes with variables

### Pseudo-classes and Pseudo-elements
- **Structural Pseudo-classes**: :nth-child, :first-of-type, :last-child
- **State Pseudo-classes**: :hover, :focus, :active, :visited
- **Pseudo-elements**: ::before, ::after, ::first-line, ::selection
- **Content Property**: Generated content with pseudo-elements
- **Advanced Selectors**: Attribute selectors and combinators

- **Device Targeting**: Specific device and orientation queries
