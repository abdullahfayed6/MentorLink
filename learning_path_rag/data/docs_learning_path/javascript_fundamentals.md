# JavaScript Fundamentals

## Core JavaScript Concepts

### Variables and Data Types
- **var, let, const**: Variable declarations and scope
- **Primitive Types**: string, number, boolean, undefined, null, symbol, bigint
- **Reference Types**: Objects, arrays, functions
- **Type coercion**: Implicit and explicit conversion

### Functions and Scope
- **Function Declarations**: Traditional function syntax
- **Function Expressions**: Anonymous and named expressions
- **Arrow Functions**: ES6 syntax and lexical this binding
- **Closures**: Function access to outer scope variables
- **IIFE**: Immediately Invoked Function Expressions

### Objects and Arrays
- **Object Creation**: Literal notation, constructor functions, Object.create()
- **Property Access**: Dot notation vs bracket notation
- **Array Methods**: push, pop, shift, unshift, splice, slice
- **Iteration Methods**: forEach, map, filter, reduce, find
- **Destructuring**: Object and array destructuring assignment

## Advanced JavaScript Features

### Asynchronous JavaScript
- **Callbacks**: Handling asynchronous operations
- **Promises**: Promise states, .then(), .catch(), .finally()
- **Async/Await**: Modern asynchronous syntax
- **Event Loop**: Understanding JavaScript's concurrency model
- **Fetch API**: Making HTTP requests

### ES6+ Features
- **Template Literals**: String interpolation and multiline strings
- **Spread Operator**: Array and object spreading
- **Rest Parameters**: Function parameters handling
- **Default Parameters**: Parameter default values
- **Modules**: import/export statements

### Error Handling
- **Try/Catch/Finally**: Exception handling
- **Custom Errors**: Creating and throwing custom error types
- **Error Propagation**: Understanding error bubbling
- **Debugging**: Using browser dev tools and console methods

## DOM Manipulation

### Selecting Elements
- **querySelector**: Single element selection
- **querySelectorAll**: Multiple element selection
- **getElementById, getElementByClassName**: Traditional methods
- **Element traversal**: parentNode, children, siblings

### Modifying Elements
- **Content Manipulation**: innerHTML, textContent, innerText
- **Attribute Manipulation**: getAttribute, setAttribute, removeAttribute
- **Style Manipulation**: style property, classList methods
- **Creating and Removing**: createElement, appendChild, removeChild

### Event Handling
- **Event Listeners**: addEventListener, removeEventListener
- **Event Object**: Properties and methods
- **Event Propagation**: Capturing, target, bubbling phases
- **Event Delegation**: Handling events on parent elements
