# Computer Networks and Protocols

## Network Fundamentals

### OSI Model Layers
- **Physical Layer**: Electrical signals, cables, and transmission media
- **Data Link Layer**: Frame formatting, error detection, and MAC addressing
- **Network Layer**: IP addressing, routing, and packet forwarding
- **Transport Layer**: TCP/UDP protocols and end-to-end communication
- **Session Layer**: Connection establishment and session management
- **Presentation Layer**: Data encryption, compression, and format conversion
- **Application Layer**: HTTP, FTP, SMTP, and user interface protocols

### TCP/IP Protocol Suite
- **Internet Protocol**: IPv4 and IPv6 addressing and packet routing
- **Transmission Control Protocol**: Reliable, ordered data delivery
- **User Datagram Protocol**: Fast, connectionless data transmission
- **Internet Control Message Protocol**: Network diagnostic and error reporting
- **Address Resolution Protocol**: MAC address resolution from IP addresses

### Network Addressing
- **IP Address Classes**: Class A, B, C address ranges and subnetting
- **Subnet Masking**: Network and host portion identification
- **CIDR Notation**: Classless Inter-Domain Routing representation
- **Private IP Ranges**: RFC 1918 private address spaces
- **Network Address Translation**: Private to public IP translation

## Routing and Switching

### Switching Concepts
- **MAC Address Learning**: Switch forwarding table construction
- **VLAN Configuration**: Virtual LAN segmentation and isolation
- **Spanning Tree Protocol**: Loop prevention in switched networks
- **Port Security**: MAC address filtering and access control
- **Link Aggregation**: Multiple physical links as single logical link

### Routing Protocols
- **Static Routing**: Manually configured routing table entries
- **Dynamic Routing**: Automatic route discovery and maintenance
- **Distance Vector**: RIP protocol and hop count metrics
- **Link State**: OSPF protocol and topology database
- **Path Vector**: BGP protocol and autonomous system routing

### Quality of Service
- **Traffic Classification**: Packet marking and priority assignment
- **Bandwidth Management**: Rate limiting and traffic shaping
- **Queue Management**: Priority queuing and congestion control
- **Jitter and Latency**: Real-time traffic optimization
- **Service Level Agreements**: Network performance guarantees

## Network Security

### Firewall Technologies
- **Packet Filtering**: IP address and port-based access control
- **Stateful Inspection**: Connection state tracking and validation
- **Application Layer Filtering**: Deep packet inspection and protocol analysis
- **Next-Generation Firewalls**: Integrated security features and threat intelligence
- **Firewall Rules**: Access control list configuration and management

### VPN Technologies
- **Site-to-Site VPN**: Network-to-network secure connections
- **Remote Access VPN**: Individual user secure remote connectivity
- **IPSec Protocol**: Network layer encryption and authentication
- **SSL/TLS VPN**: Application layer secure tunnel establishment
- **VPN Concentrators**: Centralized VPN gateway and access control

### Network Monitoring
- **SNMP Monitoring**: Simple Network Management Protocol for device monitoring
- **NetFlow Analysis**: Network traffic flow analysis and reporting
- **Packet Capture**: Network troubleshooting and security analysis
- **Network Scanning**: Port scanning and vulnerability assessment
- **Intrusion Detection**: Network-based threat detection and alerting

## Wireless Networks

### Wi-Fi Standards
- **802.11 Evolution**: Wireless standard progression and improvements
- **Frequency Bands**: 2.4GHz, 5GHz, and 6GHz spectrum usage
- **MIMO Technology**: Multiple-input multiple-output antenna systems
- **Beamforming**: Directional signal transmission optimization
- **Wi-Fi 6/6E**: Latest wireless standard features and capabilities

### Wireless Security
- **WPA3 Security**: Latest Wi-Fi security protocol and encryption
- **Enterprise Authentication**: 802.1X and RADIUS authentication
- **Wireless Intrusion Detection**: Rogue access point detection
- **RF Security**: Radio frequency analysis and threat detection
- **Guest Network Isolation**: Separate network access for visitors

### Network Design
- **Site Survey**: RF planning and coverage optimization
- **Capacity Planning**: User density and bandwidth requirements
- **Controller Architecture**: Centralized wireless network management
- **Mesh Networks**: Self-healing wireless network topologies
- **IoT Integration**: Internet of Things device connectivity and management
