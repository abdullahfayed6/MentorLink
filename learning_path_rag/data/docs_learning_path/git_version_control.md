# Git and Version Control

## Git Fundamentals

### Repository Basics
- **Git Init**: Creating new repositories
- **Git Clone**: Copying remote repositories
- **Working Directory**: Understanding the three areas
- **Staging Area**: Preparing changes for commit
- **Repository**: Committed changes and history

### Basic Git Commands
- **git add**: Adding files to staging area
- **git commit**: Creating snapshots of changes
- **git status**: Checking repository status
- **git log**: Viewing commit history
- **git diff**: Comparing changes between versions

### File Operations
- **git rm**: Removing files from repository
- **git mv**: Moving and renaming files
- **Gitignore**: Excluding files from version control
- **Untracking Files**: Removing files from Git without deletion
- **File History**: Tracking changes to specific files

## Branching and Merging

### Branch Management
- **git branch**: Creating and listing branches
- **git checkout**: Switching between branches
- **git switch**: Modern branch switching command
- **Branch Naming**: Conventions for branch names
- **Remote Tracking**: Connecting local and remote branches

### Merging Strategies
- **Fast-Forward Merge**: Linear history merging
- **Three-Way Merge**: Combining divergent branches
- **Merge Conflicts**: Resolving conflicting changes
- **Merge Tools**: Using external tools for conflict resolution
- **Squash Merging**: Combining multiple commits

### Advanced Branching
- **Git Flow**: Branching model for releases
- **Feature Branches**: Isolating new features
- **Hotfix Branches**: Quick production fixes
- **Release Branches**: Preparing for releases
- **Rebasing**: Alternative to merging for linear history

## Remote Repositories

### Remote Operations
- **git remote**: Managing remote connections
- **git push**: Uploading changes to remote
- **git pull**: Downloading and merging changes
- **git fetch**: Downloading without merging
- **Upstream Branches**: Tracking remote branch changes

### Collaboration Workflows
- **Centralized Workflow**: Single shared repository
- **Feature Branch Workflow**: Branch-based collaboration
- **Gitflow Workflow**: Structured branching model
- **Forking Workflow**: Distributed development model
- **Pull Requests**: Code review and integration

### Git Hosting Services
- **GitHub**: Features and integration tools
- **GitLab**: Self-hosted and cloud options
- **Bitbucket**: Atlassian's Git hosting service
- **SSH Keys**: Secure authentication setup
- **Access Control**: Managing repository permissions
