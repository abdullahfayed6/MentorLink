# Programming Fundamentals - Beginner Guide

## What is Programming?

Programming is the process of creating instructions for computers to follow. These instructions are written in programming languages that computers can understand and execute.

## Basic Programming Concepts

### 1. Variables
Variables are containers that store data values. Think of them as labeled boxes where you can put information.

```python
name = "Alice"
age = 25
height = 5.6
```

### 2. Data Types
- **Integers**: Whole numbers (1, 2, 100)
- **Strings**: Text data ("Hello", "Programming")
- **Floats**: Decimal numbers (3.14, 2.5)
- **Booleans**: True or False values

### 3. Control Structures
Control structures determine the flow of program execution:
- **If statements**: Make decisions
- **Loops**: Repeat actions
- **Functions**: Reusable code blocks

### 4. Input and Output
Programs often need to interact with users:
- Input: Getting data from users
- Output: Displaying results to users

## Getting Started
1. Choose a programming language (Python recommended for beginners)
2. Set up a development environment
3. Write your first "Hello, World!" program
4. Practice with simple exercises
